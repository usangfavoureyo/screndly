## Core Principle (Non-Negotiable)

> **If a change would require spatial math, conditional positioning, or mask manipulation, it belongs in a new PSD template — not in code.**

---

## System Boundaries

| Role | Responsibility |
|------|----------------|
| **Designer** | Geometry, anchors, masks, typography |
| **Screndly** | State, rules, orchestration |
| **Photopea** | Deterministic execution |
| **User** | Content + scalar choices |

**No role crosses boundaries.**

## 1. Template Authoring (Designer – One-Time Work)

### A. Text System

```
TEXT
 ├── Header Large   (VISIBLE by default)
 ├── Header Medium  (HIDDEN)
 └── Header Small   (HIDDEN)

 ├── Subtext Large  (VISIBLE or HIDDEN based on design)
 ├── Subtext Medium (HIDDEN)
 └── Subtext Small  (HIDDEN)
```

**Rules:**
- ✅ All variants share the **same anchor point**
- ✅ Only **one variant visible** per text field
- ✅ Geometry is **final** – no runtime movement
- ✅ Paragraph text boxes with fixed width
- ✅ Auto-leading enabled

**Character Thresholds (Recommended):**

| Variant | Characters | Use Case |
|---------|-----------|----------|
| **Large** | 0–59 | Short, punchy headlines |
| **Medium** | 60–99 | Standard news headlines |
| **Small** | 100–120 | Longer, detailed headlines |

---

### B. Image System

```
IMAGE
 └── Hero Image (Smart Object)
```

**Rules:**
- ✅ Single Smart Object layer
- ✅ Replaced at runtime via Photopea
- ✅ Optional transform values only (scale, offset)
- ✅ No dynamic cropping or repositioning

---

### C. Gradient Overlay System

```
OVERLAY_GRADIENT
 ├── Overlay Top    (Solid Color Adjustment Layer + Gradient Mask)
 ├── Overlay Bottom (Solid Color Adjustment Layer + Gradient Mask)
 ├── Overlay Left   (Solid Color Adjustment Layer + Gradient Mask)
 └── Overlay Right  (Solid Color Adjustment Layer + Gradient Mask)
```

**Rules:**
- ✅ **Exactly one overlay visible** by default (recommend: Bottom)
- ✅ All masks are **pre-authored** (linear gradients)
- ✅ **No runtime mask edits**, rotations, or geometry math
- ✅ Each overlay: Solid Color Adjustment Layer with gradient mask
- ✅ All overlays use identical opacity defaults

## 2. Template Ingestion (Screndly)

**On Upload:**

```typescript
1. Load PSD into Photopea (hidden iframe)
2. Execute layer analysis script
3. Parse layer tree and detect:
   - Text variant groups (Large/Medium/Small)
   - Smart Object image layer
   - Overlay variants (Top/Bottom/Left/Right)
4. Cache layer metadata
5. Generate static preview image
6. Add template to library
```

**Validation:**
- ❌ **Reject** templates missing required layers
- ❌ **Reject** templates with ambiguous naming
- ✅ **Accept** only templates conforming to structure

**No layout inference. No heuristics. No guessing.**

## 3. User Composition (UI Layer)

### User Controls (Scalar State Only)

#### **Text Section**
- **Header Text Input**
  - Character counter with live feedback
  - Hard limit enforced (e.g., 120 chars max)
  - Color picker for text color
  
- **Subtext Input** (if template supports it)
  - Independent character counter
  - Independent color picker

#### **Image Section**
- **Upload from Device** or **Search TMDb**
- Optional composition controls:
  - Horizontal position (0–100%)
  - Vertical position (0–100%)
  - Zoom (80%–150%)

#### **Overlay Section**
- **Toggle:** Overlay ON/OFF
- **Direction Selector:** Top | Bottom | Left | Right
- **Color Picker:** RGB/HEX
- **Opacity Slider:** 0–85%

**User never controls:**
- ❌ Text position
- ❌ Text size
- ❌ Mask geometry
- ❌ Layer order
- ❌ Anchor points

## 4. Variant Resolution (Screndly Logic)

### Text Variant Selection (Deterministic)

```typescript
function selectHeaderVariant(text: string): 'large' | 'medium' | 'small' {
  const chars = text.length;
  
  if (chars < 60) return 'large';
  if (chars < 100) return 'medium';
  return 'small';
}
```

**Execution:**
```javascript
// Photopea script (generated by Screndly)
hideLayer("Header Large");
hideLayer("Header Medium");
hideLayer("Header Small");

showLayer("Header Medium"); // Selected variant
setLayerText("Header Medium", userText);
setLayerColor("Header Medium", userColor);
```

**Same logic applies to subtext variants (independent thresholds).**

---

### Overlay Resolution (Deterministic)

```typescript
function applyOverlay(
  enabled: boolean,
  direction: 'top' | 'bottom' | 'left' | 'right',
  color: string,
  opacity: number
) {
  if (!enabled) {
    hideAllOverlays();
    return;
  }
  
  hideAllOverlays();
  showOverlay(direction);
  setOverlayColor(direction, color);
  setOverlayOpacity(direction, opacity);
}
```

**Photopea Execution:**
```javascript
// Hide all overlays
overlays.top.visible = false;
overlays.bottom.visible = false;
overlays.left.visible = false;
overlays.right.visible = false;

// Activate selected overlay
overlays.bottom.visible = true;
overlays.bottom.opacity = 70;
overlays.bottom.color = RGB(0, 0, 0);
```

**No mask manipulation. No transforms. Just visibility + scalar values.**

## 5. Photopea Execution (Deterministic)

### Script Operations (Whitelist)

Photopea receives a script that does **only:**

✅ **Visibility toggles**
```javascript
layer.visible = true;
layer.visible = false;
```

✅ **Text assignment**
```javascript
layer.textItem.contents = "New text";
layer.textItem.color = RGB(255, 255, 255);
```

✅ **Solid Color adjustment value updates**
```javascript
layer.opacity = 70;
layer.color = RGB(0, 0, 0);
```

✅ **Smart Object replacement**
```javascript
replaceSmartObject(layer, imageDataUrl);
```

✅ **Export to JPEG**
```javascript
document.flatten();
document.saveAs("output.jpg", jpegOptions);
```

---

### Forbidden Operations (Blacklist)

❌ **Layer positioning** (`layer.translate()`)  
❌ **Mask editing** (`mask.feather`, `mask.density`)  
❌ **Rotation** (`layer.rotate()`)  
❌ **Dynamic resizing** (beyond Smart Object scale)  
❌ **Conditional layout logic**  
❌ **Anchor point changes**  

**Zero layout decisions.**

## 6. Export & Publish

```typescript
async function renderAndPublish(designData: DesignData) {
  // 1. Generate Photopea script
  const script = generateRenderScript(designData, templateMetadata);
  
  // 2. Execute in Photopea
  const jpegBlob = await photopeaService.executeScript(script);
  
  // 3. Create local preview
  const previewUrl = URL.createObjectURL(jpegBlob);
  
  // 4. Add to rendered designs
  addRenderedDesign({
    id: generateId(),
    outputUrl: previewUrl,
    data: designData,
    createdAt: new Date()
  });
  
  // 5. Upload to Backblaze B2 (on publish)
  const publicUrl = await uploadToBackblaze(jpegBlob);
  
  // 6. Post to social platforms
  await postToTwitter(publicUrl, designData.headerText);
  await postToInstagram(publicUrl, designData.headerText);
  
  // 7. Log activity
  logActivity('design_published', { platforms: ['Twitter', 'Instagram'] });
}
```

## Error Handling

### Template Ingestion Errors:
```typescript
if (!detectedLayers.hasHeaderVariants) {
  throw new Error('Template missing header variants (Large/Medium/Small)');
}

if (!detectedLayers.hasBackground) {
  throw new Error('Template missing Smart Object image layer');
}

if (overlayCount !== 4) {
  throw new Error('Template must have exactly 4 overlay variants');
}
```

### Runtime Errors:
```typescript
try {
  await photopeaService.renderDesign(data, template);
} catch (error) {
  toast.error('Rendering failed. Please try again.');
  logError('photopea_render_failed', error);
  // Fallback: Use CSS preview as placeholder
}
```

## Documentation for Designers

### Template Creation Checklist:

**Step 1: Set Up Canvas**
- Create new document (e.g., 1080x1350px for Instagram)
- Set up guides for safe zones

**Step 2: Create Text Variants**
```
Header Large   - 72pt, Bold, Top-aligned at Y=100px
Header Medium  - 56pt, Bold, Top-aligned at Y=100px (same anchor!)
Header Small   - 44pt, Bold, Top-aligned at Y=100px (same anchor!)
```
- Use paragraph text boxes
- Set fixed width (e.g., 960px)
- Enable auto-leading
- Make only Large visible

**Step 3: Create Image Layer**
- Convert to Smart Object
- Name: "Hero Image" or "Background"

**Step 4: Create Overlay Variants**
```
OVERLAY_GRADIENT group:
  Overlay Top    - Solid Color (#000000) + Gradient Mask (top-down)
  Overlay Bottom - Solid Color (#000000) + Gradient Mask (bottom-up)
  Overlay Left   - Solid Color (#000000) + Gradient Mask (left-right)
  Overlay Right  - Solid Color (#000000) + Gradient Mask (right-left)
```
- Make only Bottom visible
- Set default opacity: 70%

**Step 5: Save & Test**
- Save as PSD
- Upload to Screndly
- Verify layer detection
- Test with various text lengths
- Test overlay directions

## Glossary

**Anchor Point** – Fixed position where text variants are aligned (e.g., top-left, bottom-center)

**Variant** – Pre-designed layer at different sizes (Large/Medium/Small) sharing the same anchor

**Scalar Value** – Numeric or enum parameter (color, opacity, direction) with no geometry impact

**Deterministic Execution** – Same inputs always produce identical outputs

**Visibility Switch** – Showing/hiding pre-authored layers without modifying their geometry

**Strategy 2** – Multi-size text variant approach (vs. Strategy 1: single resizable box)

**Strategy 4** – Character counters with editorial limits in UI
